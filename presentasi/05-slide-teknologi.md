# Slide 05: Teknologi

**Waktu:** 45 detik

## Tampil di layar

| Lapisan | Pilihan |
|---|---|
| Backend + tampilan | PHP 8 (tanpa framework) |
| Database | MySQL (phpMyAdmin) |
| UI | Bootstrap 5.3 (lokal) |
| Interaksi | JavaScript murni (±50 baris) |
| Ikon | SVG inline |
| Penyajian | XAMPP (localhost) dan Docker |

## Naskah

"Aplikasi memakai PHP polos tanpa framework, supaya seluruh alurnya bisa saya jelaskan baris demi baris. Database MySQL yang dikelola lewat phpMyAdmin. Tampilan memakai Bootstrap 5.3 versi stabil, yang file-nya saya simpan di dalam proyek, jadi tidak membutuhkan internet. Ikon berupa SVG langsung di kode, dan JavaScript hanya sekitar lima puluh baris untuk dialog konfirmasi. Aplikasi dijalankan di XAMPP lewat localhost, dan saya juga menyediakan jalur Docker."

## Mengapa pilihan ini?

- **Tanpa framework:** sesuai ketentuan, dan memudahkan penjelasan.
- **Offline:** laptop ujian tidak ada internet. Itu sebabnya tidak ada CDN dan font web.
- **Bootstrap:** stabil dan umum dikenal, jadi tampilan cepat konsisten.
