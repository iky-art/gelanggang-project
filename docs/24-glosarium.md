# 24. Glosarium

| Istilah | Arti |
|---|---|
| **Arena** | Tempat atau meja pertandingan. Dipakai pada deteksi bentrok |
| **Bagan gugur** | Pertandingan sistem kalah langsung tersingkir (single elimination) |
| **Bye** | Tim lolos otomatis ke ronde berikutnya tanpa bertanding karena jumlah tim bukan pangkat dua |
| **CRUD** | Create, Read, Update, Delete: empat operasi dasar data |
| **CSRF** | Serangan yang membuat browser pengguna mengirim formulir tanpa disadari. Dicegah dengan token |
| **Dikunci** | Skor yang sudah disimpan dan tidak bisa diubah panitia |
| **Foreign key** | Kolom yang menunjuk baris di tabel lain dan menjaga konsistensi |
| **GM / GK / SG** | Skor memasukkan / skor kemasukan / selisih |
| **Grup** | Kelompok tim yang bermain liga di antara mereka |
| **Head-to-head (H2H)** | Hasil pertemuan langsung antar tim yang sama kuat |
| **Hash** | Sidik jari satu arah dari kata sandi. Tidak bisa dibalik jadi sandi asli |
| **Koreksi** | Perubahan skor yang sudah terkunci, hanya oleh admin dengan alasan |
| **Liga** | Semua tim bertemu semua tim; peringkat ditentukan poin |
| **Log aktivitas** | Catatan siapa melakukan apa dan kapan |
| **Mini-liga** | Klasemen sementara yang hanya memakai laga antar tim yang sama kuat |
| **Optimistic locking** | Pengecekan nomor versi agar dua pengubah tidak saling menimpa diam-diam |
| **PDO** | Antarmuka PHP untuk database dengan dukungan prepared statement |
| **Pola ular (snake)** | Pembagian grup bolak-balik agar kekuatan merata |
| **Post/Redirect/Get** | Setelah POST, halaman dialihkan agar refresh tidak mengirim ulang |
| **Prepared statement** | Query dengan tempat kosong yang diisi aman, mencegah SQL injection |
| **Pulang-pergi** | Setiap tim bertemu dua kali |
| **Ronde** | Satu putaran laga di mana tiap tim paling banyak main sekali |
| **Seed** | Peringkat unggulan awal tim. Seed 1 dianggap terkuat |
| **Seri total** | Dua tim sama pada semua kriteria peringkat. Perlu nilai undian |
| **Slot** | Satu jadwal waktu yang bisa dipakai beberapa arena bersamaan |
| **Transaksi** | Beberapa perubahan database yang berhasil semua atau gagal semua |
| **Undian** | Nilai pemutus terakhir yang diisi panitia, misalnya hasil undian koin |
| **Versi (laga)** | Angka yang naik setiap laga berubah, untuk mendeteksi konflik |
| **XSS** | Penyisipan skrip lewat input. Dicegah dengan escape keluaran |
