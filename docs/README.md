# Dokumentasi Gelanggang

Gelanggang adalah aplikasi manajemen turnamen e-sport sekolah (PHP + MySQL + Bootstrap) yang dibuat sebagai contoh proyek UKK RPL. Folder ini berisi dokumentasi lengkap: cara memasang, cara kerja, dan cara menjelaskannya ke penguji.

## Mulai dari mana?

| Kamu ingin... | Baca |
|---|---|
| Menjalankan aplikasi di laptop sekolah | 03, 04 |
| Menjalankan lewat Docker atau Termux | 05, 06 |
| Memahami struktur kode dan database | 07, 08 |
| Memahami logika (klasemen, bagan, skor) | 10 sampai 15 |
| Menyiapkan presentasi UKK | 22 dan folder `../presentasi/` |

## Daftar dokumen

1. `01-ringkasan-proyek.md`: apa itu Gelanggang dan apa yang bisa dilakukan
2. `02-persyaratan-sistem.md`: versi PHP, MySQL, dan browser
3. `03-memasang-bootstrap-offline.md`: memasang Bootstrap agar jalan tanpa internet
4. `04-instalasi-xampp-windows.md`: langkah di laptop sekolah (tanpa terminal)
5. `05-instalasi-docker.md`: jalur Docker
6. `06-instalasi-termux-android.md`: jalur Termux di Android
7. `07-struktur-folder.md`: isi tiap folder dan file
8. `08-struktur-database.md`: tabel, kolom, dan relasi
9. `09-peran-dan-alur-pengguna.md`: admin, panitia, penonton
10. `10-aturan-turnamen.md`: format, status, dan siklus hidup turnamen
11. `11-logika-klasemen.md`: cara peringkat dihitung
12. `12-logika-jadwal-liga.md`: pasangan laga, pembagian grup, penyusunan waktu
13. `13-logika-bagan-gugur.md`: seed, bye, dan perebutan juara 3
14. `14-logika-input-skor.md`: transaksi, penguncian, dan koreksi
15. `15-anti-bentrok-jadwal.md`: deteksi bentrok tim dan arena
16. `16-keamanan.md`: lapisan keamanan dan batasannya
17. `17-crud-per-modul.md`: operasi tambah, lihat, ubah, hapus tiap modul
18. `18-panduan-penggunaan.md`: skenario lengkap dari nol sampai juara
19. `19-pengujian.md`: uji otomatis, uji manual, dan status verifikasi
20. `20-pemecahan-masalah.md`: error yang sering muncul dan solusinya
21. `21-kustomisasi.md`: mengganti nama, warna, aturan, dan bahasa
22. `22-pemetaan-ukk.md`: cara memetakan fitur ke penilaian UKK
23. `23-keterbatasan-dan-pengembangan.md`: yang belum ada dan ide lanjutan
24. `24-glosarium.md`: istilah yang dipakai

## Catatan kejujuran

Beberapa hal belum bisa diverifikasi saat proyek ini dibuat. Lihat bagian "Status verifikasi" di `19-pengujian.md` sebelum mengklaim apa pun di depan penguji.
