Klasemen, bagan, dan jadwal turnamen sekolah, dihitung otomatis

Gelanggang membantu panitia turnamen e-sport sekolah mengelola tim, jadwal, dan skor. Aplikasinya berjalan di localhost, tanpa internet.

Tonton video demo Pasang di komputer

Gratis, lisensi MIT. Tidak ada versi online: aplikasi PHP ini dijalankan sendiri di XAMPP, Docker, atau Termux.

Fitur

Yang bisa dikerjakan panitia

  1. Tiga format turnamen

    Fase grup lalu gugur, liga satu klasemen, atau gugur langsung. Poin menang, seri, dan kalah bisa diatur.

  2. Tim dan pemain

    Daftar tim dengan warna dan seed, pemain dengan nickname unik per tim, dan satu kapten per tim.

  3. Jadwal otomatis

    Pasangan liga dengan metode lingkaran, lalu waktu dan arena disusun per ronde. Satu tim tidak main dua kali di slot yang sama.

  4. Klasemen otomatis

    Tie-break berurutan, dan seri total ditandai agar panitia yang memutuskan lewat nilai undian.

  5. Bagan gugur

    Mendukung jumlah tim bukan pangkat dua (bye), seed dari hasil grup, dan perebutan juara 3.

  6. Skor yang aman

    Disimpan dalam satu transaksi, dikunci, dan dikoreksi hanya oleh admin dengan alasan yang masuk log.

Cara kerjanya

Tiga bagian logika yang paling penting

Perhitungannya ditulis sebagai fungsi murni di app/logic/, terpisah dari database, sehingga bisa diuji sendiri.

Klasemen dengan tie-break yang jelas

Peringkat ditentukan berurutan. Bila dua tim sama di satu kriteria, kriteria berikutnya yang dipakai.

  1. Poin
  2. Selisih skor
  3. Head-to-head: hanya laga antar tim yang sama kuat
  4. Total skor memasukkan
  5. Nilai undian dari panitia

Bila semuanya sama, tim ditandai seri total dan aplikasi menolak menentukan siapa yang lolos sampai panitia mengisi undian.

Contoh klasemen dengan head-to-head
TimMMnSKSGPoin
Citra3210+27
Aster311104
Dewa3102−13
Bima3102−13

Contoh data dari uji otomatis. Dewa dan Bima sama-sama 3 poin dengan selisih −1. Dewa menang 1–0 saat bertemu langsung, jadi Dewa di atas Bima, walau secara abjad Bima lebih dulu.

Bagan gugur dengan bye dan seed standar

Ukuran bagan dibulatkan ke pangkat dua terdekat. Selisihnya menjadi bye: tim unggulan lolos otomatis ke ronde berikutnya.

Urutan seed standar membuat seed 1 dan 2 baru bisa bertemu di final. Pada format grup, juara dan runner-up diatur agar ronde pertama tidak mempertemukan tim dari grup yang sama.

Pemenang tiap laga pindah ke laga berikutnya lewat penunjuk menang_ke_id.

Contoh 6 tim → bagan 8, dua bye

  • Seed 1 · bye
  • Seed 4 vs Seed 5
  • Seed 2 · bye
  • Seed 3 vs Seed 6

Coba jumlah tim lain di bagian Coba sendiri.

Satu simpan skor, satu transaksi

Menyimpan skor menyentuh banyak hal sekaligus. Karena itu semuanya dikerjakan dalam satu transaksi database: berhasil bersama atau dibatalkan bersama.

Dua panitia yang membuka laga yang sama tidak bisa saling menimpa: nomor versi laga dicek saat menyimpan.

  1. Validasi skor 0–99
  2. Kunci baris dan cek nomor versi
  3. Tentukan pemenang sesuai aturan seri
  4. Simpan skor dan kunci laga
  5. Majukan pemenang ke laga berikutnya
  6. Perbarui status turnamen dan catat log

Pasang

Tiga cara menjalankan di komputer sendiri

Butuh PHP 7.4 atau lebih baru dan MySQL atau MariaDB. File Bootstrap diunduh sekali, setelah itu aplikasi berjalan tanpa internet.

XAMPP di Windows (tanpa terminal)
  1. Salin folder proyek ke C:\xampp\htdocs\gelanggang.
  2. Di XAMPP, jalankan Apache dan MySQL.
  3. Buka localhost/phpmyadmin, tab Impor, pilih database/gelanggang.sql, lalu Kirim. Opsional: impor juga database/data_contoh.sql.
  4. Pasang Bootstrap: buka localhost/gelanggang/siapkan-aset.php saat ada internet, klik tombolnya sekali.
  5. Buka localhost/gelanggang/ dan buat akun admin pertama di halaman setup.
Docker 
cd gelanggang/docker
docker compose up -d --build

Aplikasi di localhost:8080, phpMyAdmin di localhost:8081. Skema database dimuat otomatis.

Termux di Android 
pkg install php mariadb curl unzip
mysql_install_db
mysqld_safe --datadir=$PREFIX/var/lib/mysql &
mariadb -u root < ~/gelanggang/database/gelanggang.sql
cd ~/gelanggang/assets/vendor
curl -LO https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css
curl -LO https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js
cd ~/gelanggang
DB_HOST=127.0.0.1 php -S 0.0.0.0:8080

Buka localhost:8080 di peramban ponsel. Server bawaan PHP tidak membaca .htaccess, jadi jangan dibuka ke jaringan umum.

Pertanyaan umum

Yang sering ditanyakan

Apakah ada demo online yang bisa dicoba?

Belum. Gelanggang adalah aplikasi PHP dengan database MySQL, sedangkan situs ini hanya halaman statis. Untuk mencobanya, jalankan sendiri di komputer atau ponsel. Kalkulator di bagian Coba sendiri dan video demo adalah yang bisa dilihat di sini.

Bisa dipakai tanpa internet?

Bisa. Satu-satunya yang butuh internet adalah mengunduh dua file Bootstrap saat pemasangan awal. Setelah itu tidak ada CDN, font web, atau API luar.

Memakai framework apa?

Tidak ada framework. PHP polos, MySQL lewat PDO, dan Bootstrap 5.3 untuk tampilan, sehingga setiap alurnya bisa dibaca dan dijelaskan baris demi baris.

Amankah dipasang di internet publik?

Belum disiapkan untuk itu. Aplikasi dirancang untuk jaringan lokal. Untuk server publik, kamu perlu HTTPS, kata sandi database khusus, dan menghapus siapkan-aset.php serta folder tests/. Rinciannya ada di dokumen keamanan.

Apa yang belum ada?

Format Swiss dan double elimination, skor per game untuk seri Bo3, logo tim, dan reset kata sandi lewat email. Daftar lengkapnya ada di dokumen keterbatasan dan pengembangan.

Bolehkah dipakai untuk UKK?

Kode dan dokumennya disediakan sebagai bahan belajar dengan lisensi MIT. Kalau dipakai untuk ujian, pahami setiap bagiannya dan siapkan penjelasan dengan kata-katamu sendiri. Penguji biasanya meminta penjelasan kode, bukan hanya demo.
